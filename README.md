# Pomodoro Study Timer

## About My Project

I created a Pomodoro Study Timer as part of my Faglig Fornyelse project, where I chose to learn TypeScript.

The purpose of my project is to help students focus on studying by using a 25-minute countdown timer.

I built this project using TypeScript, HTML, and CSS without using any frameworks.

## What I Created

My Pomodoro Timer includes:

- A 25-minute countdown
- A Start button to begin studying
- A Pause button to stop the countdown temporarily
- A Reset button to restart the timer
- Messages that change depending on the timer's status

## Technologies I Used

- **TypeScript:** To create the timer functionality and handle button clicks.
- **HTML:** To structure the webpage.
- **CSS:** To design and style the timer.
- **JavaScript:** Generated by compiling my TypeScript code.

## How My Project Works

I used TypeScript to create a countdown starting from 25 minutes.

I used `setInterval()` to decrease the time every second and `clearInterval()` to pause the timer.

I also used `querySelector()` to select HTML elements and `addEventListener()` to connect the buttons to their functions.

## What I Learned

While working on this project, I learned how to:

- Write functions and variables in TypeScript.
- Use types such as `number`.
- Work with HTML elements through DOM manipulation.
- Handle button clicks.
- Create a countdown using TypeScript.
- Compile TypeScript into JavaScript.

One challenge I experienced was getting the timer countdown and buttons to work correctly.

I learned how important it is to match HTML IDs with TypeScript selectors and compile the TypeScript file after making changes.
